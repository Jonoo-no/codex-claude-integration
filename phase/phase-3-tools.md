## 🤔 这两个工具做什么？

简单说：**让你有 API Key 就能用上 Codex 和 Claude**。

你不需要写代码、不需要配环境、不需要学编程。下载一个桌面程序 → 打开 → 填入你的 API Key → 直接开始用 AI。

打个比方：
- 你有两张"加油卡"（OpenAI 和 Anthropic 的 API Key）
- CC-Switch 和 Echo Bird 就是两台"刷卡机"
- 把卡插进去，就能"加油"——也就是使用 AI 模型
