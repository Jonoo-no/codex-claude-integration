# 10. CC-Switch 界面与模型配置

## 🎯 本课目标

认识 CC-Switch 的主要界面，学会添加模型并填入 API Key——这是最关键的一步。

> ⏱️ **预计时间**：20-30 分钟
> 🔑 **核心**：把你的 API Key 填入 CC-Switch，让它能调用 AI 模型

---

## 🖥️ 认识主界面

打开 CC-Switch 后，你会看到主界面。虽然版本更新可能导致界面略有不同，但核心功能区通常包括：

| 区域 | 位置 | 功能 |
|------|------|------|
| **模型列表** | 左侧或顶部 | 显示你已经添加的所有模型 |
| **对话区** | 中央 | 与 AI 对话的地方 |
| **输入框** | 底部 | 输入你想问的问题 |
| **设置 / 模型管理** | 菜单栏或右上角 | 添加、删除、管理模型 |

---

## 🔑 第二步：进入模型管理

这是最重要的一步——**添加模型并填入 API Key**。

1. 在 CC-Switch 界面中找到 **"模型管理"** 或 **"设置"** 入口
   - 可能在菜单栏的"文件"或"设置"中
   - 也可能有一个齿轮图标 ⚙️
   - 或者在主界面有一个"添加模型"的按钮

2. 点击进入后，你会看到模型管理界面

---

## ➕ 第三步：添加一个新模型

在模型管理界面中：

1. 点击 **"添加模型"** 或 **"新增"** 按钮

2. 你会看到一个表单，需要填写以下信息：

   | 字段 | 填什么 | 说明 |
   |------|--------|------|
   | **模型名称** | 随便写，比如"我的 Codex" | 只是给你自己看的标签 |
   | **模型类型** | 选择 OpenAI 或 Anthropic | 根据你的 Key 来源选择 |
   | **API Key** | 粘贴你的 Key | 这是最重要的！从你之前保存的地方复制过来 |
   | **API 地址**（如有） | 通常用默认值即可 | 一般不需要改 |

3. **填写 API Key**：
   - 打开你之前保存 Key 的地方（教程 05 和 06 中创建的）
   - 复制完整的 Key（`sk-proj-...` 或 `sk-ant-api03-...`）
   - 粘贴到 API Key 输入框中

4. 点击 **"保存"** 或 **"确认"**

---

## 📋 第四步：添加第二个模型

重复第三步，这次添加另一个平台的模型。例如：

- 第一次添加：OpenAI API Key → 标签写"Codex"
- 第二次添加：Anthropic API Key → 标签写"Claude"

添加完成后，你的模型列表中应该有两个模型了。

---

## 🔍 第五步：检查配置是否正确

1. 回到主界面
2. 在模型列表中，你应该能看到刚才添加的模型
3. 试试切换到不同的模型，看能否正常切换

如果模型名称旁边有一个绿色圆点或"已连接"标识，说明配置成功。

---

## ⚠️ 常见错误

| 错误现象 | 可能原因 | 怎么解决 |
|----------|---------|---------|
| 添加后显示"连接失败" | API Key 粘贴时多了空格或少了字符 | 重新复制粘贴，确保完整 |
| 找不到"添加模型"按钮 | 界面版本不同 | 看看菜单栏里的"设置"或"文件" |
| Key 粘贴后显示为 `****` | 这是正常的安全掩码 | 不用担心，Key 已保存 |
| 模型列表是空的 | 还没有添加模型 | 进模型管理添加 |
| 添加后无法选择 | 可能需要重启 CC-Switch | 关掉重新打开 |

---

## 📊 两种模型的对比

在 CC-Switch 中，你添加的 Codex（OpenAI）和 Claude（Anthropic）会并排显示在模型列表中。使用时根据需求选择：

| 用 Codex 的场景 | 用 Claude 的场景 |
|----------------|-----------------|
| 写代码、调试 bug | 分析长文档 |
| 代码翻译（Python→JS） | 写作、润色 |
| 快速问答 | 深度推理 |
