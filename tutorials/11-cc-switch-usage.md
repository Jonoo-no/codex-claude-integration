# 11. CC-Switch 实战使用

## 🎯 本课目标

学会在日常中熟练使用 CC-Switch，包括切换模型、对比回答和管理用法。

> ⏱️ **预计时间**：20-30 分钟
> 🎮 **类型**：实际操作

---

## 🎮 场景一：分别与 Codex 和 Claude 对话

你已经添加了两个模型。现在试试分别问它们同一个问题，对比回答。

### 操作步骤

1. 在 CC-Switch 主界面，从模型列表中选择 **Codex（OpenAI）**
2. 在输入框输入：
   ```
   用一句话解释什么是递归
   ```
3. 按回车，等待回复
4. 记下 Codex 的回答
5. 切换到 **Claude（Anthropic）**
6. 输入**完全一样的问题**
7. 对比两个回答的差异

你会发现：同一个问题，两个 AI 的回答风格不同——这就是为什么有的场景更适合 Codex，有的更适合 Claude。

---

## 💻 场景二：让 Codex 写代码，让 Claude 解释代码

这是最常用、最实用的场景。

### 第一步：用 Codex 写代码

1. 切换到 **Codex**
2. 输入：
   ```
   用 Python 写一个函数，判断一个字符串是否是回文。
   回文就是正读反读都一样的字符串，比如 "radar"。
   ```
3. Codex 会生成一段 Python 代码

### 第二步：让 Claude 解释这段代码

1. 复制 Codex 生成的代码
2. 切换到 **Claude**
3. 输入：
   ```
   请用通俗易懂的语言解释下面这段代码的每一步在做什么：
   
   [粘贴代码在这里]
   ```
4. Claude 会用大白话解释代码逻辑

### 为什么这样分工？

- Codex 擅长**生成代码**——它在代码数据上训练最多
- Claude 擅长**解释和教学**——它的文字更清楚易懂

> 💡 这就是"多模型协作"的核心思想：不同模型各有长处，取长补短。

---

## 🔄 场景三：日常使用建议

### 问编程问题

```
✅ 用 Codex：写代码、修 bug、解释报错
🤔 如果 Codex 解释得不够清楚 → 切到 Claude 重新问
```

### 问知识性问题

```
✅ 用 Claude：分析、总结、解释概念
🤔 如果需要代码示例 → 切到 Codex 让它写
```

### 简单闲聊

```
随便用哪个都行，差别不大
```

---

## 💡 使用技巧

| 技巧 | 说明 |
|------|------|
| **先 Codex 后 Claude** | 写代码用 Codex，解释用 Claude |
| **同一个问题问两边** | 对比两个 AI 的回答，取长补短 |
| **不满意就换模型** | AI 回答不行？切换到另一个重新问一遍 |
| **保留对话记录** | CC-Switch 通常会自动保存历史对话 |

## 🆘 常见问题

### Q: 某个模型发不了消息？

**排查步骤**：
1. 检查模型管理中该模型的 API Key 是否填写正确
2. 检查 API Key 是否过期或额度用完
3. 检查网络是否正常
4. 尝试删除该模型 → 重新添加 → 重新粘贴 Key

### Q: 回复速度很慢？

这是正常的——AI 模型需要时间生成回复。如果特别慢：
- 检查网络状况
- 简单问题通常回复更快
- 不同模型的响应速度不同

### Q: 能同时打开两个对话窗口吗？

看 CC-Switch 版本。大部分版本支持同时打开多个对话。

### Q: 和直接上 ChatGPT 网页版有什么区别？

| 对比 | CC-Switch | ChatGPT 网页版 |
|------|-----------|---------------|
| 费用 | 按 API 用量扣费 | 免费版有限制 |
| 模型选择 | Codex + Claude 都能用 | 只有 OpenAI 的模型 |
| 隐私 | Key 在本地 | 数据在云端 |
| 使用门槛 | 需要 API Key | 注册就行 |
