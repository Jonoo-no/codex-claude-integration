# 04. API 基础概念

## 🎯 什么是 API？

**API** = Application Programming Interface（应用程序编程接口）

用大白话讲：**API 就像一个餐厅里的服务员**。

你（顾客）看菜单点菜，服务员把你的订单传给厨房，厨房做好菜，服务员再把菜端给你。你不需要知道厨房里发生了什么——你只需要会点菜就行。

在电脑的世界里：
- **你** = 你的程序（比如一个网页、一个 App）
- **服务员** = API
- **厨房** = 背后的大模型（比如 GPT、Claude）
- **菜单** = API 文档（告诉你"可以点什么"和"怎么点"）

---

## 📬 请求和响应

API 通信就像收发快递：

```
你发送「请求」（Request）
      ↓
服务器收到请求，处理
      ↓
你收到「响应」（Response）
```

### 一个简单的例子

假设你问 AI："你好，请介绍一下自己"

你的程序会发送一个请求（大概长这样）：

```json
{
  "model": "claude-sonnet-4-6",
  "message": "你好，请介绍一下自己"
}
```

AI 服务器收到后，返回一个响应：

```json
{
  "response": "你好！我是 Claude，一个由 Anthropic 开发的 AI 助手..."
}
```

整个过程你的程序只做了两件事：**发送问题 → 接收答案**。中间 AI 怎么理解、怎么推理、怎么生成文字，你不需要关心。

## 🔗 HTTP 基础（只需要知道这些）

API 通常通过 **HTTP**（就是浏览器上网用的那个协议）进行通信。你只需要知道三个概念：

### 1. URL（地址）

就像寄快递需要地址，调用 API 也需要一个网址：

```
https://api.openai.com/v1/chat/completions
```

这个地址叫 **endpoint**（端点）。不同的功能有不同的 endpoint。

### 2. Method（方法）

你"想干什么"——最常见的两种：

| 方法 | 含义 | 什么时候用 |
|------|------|-----------|
| **GET** | 获取数据 | 查天气、查股价、获取信息 |
| **POST** | 发送数据 | 问 AI 问题、上传文件、提交表单 |

调用 AI 模型基本上都是 **POST**，因为你要把问题"发送"给它。

### 3. Headers（头部信息）

附带在请求上的额外信息，最重要的一个是：

```
Authorization: Bearer sk-your-api-key-here
```

这就是你的 **API Key**，相当于你的"身份证"。服务器看到它才知道"哦，是你在调用，可以扣你账户里的钱"。

---

## 🔑 什么是 API Key？

**API Key** 就是一串长长的字母数字组合，用来证明你的身份。

长这样：
```
sk-proj-abc123def456ghi789jkl...
```

它就像你的银行卡密码——谁拿到它，谁就能以你的名义调用 API（花你的钱）。

> ⚠️ **记住一件事**：API Key 绝对不能公开，不能发到网上，不能传到 GitHub！

## 💰 费用说明

调用 AI API 是**按量付费**的——用多少付多少，不是包月。

- OpenAI 新用户通常有**免费额度**（约 $5，会过期）
- Anthropic 新用户也有一定的**免费额度**

注册时可能需要绑卡，但不用担心，不超免费额度就不会扣钱。具体价格可以在各平台的 Pricing 页面查看。
