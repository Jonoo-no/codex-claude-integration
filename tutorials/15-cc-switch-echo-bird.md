# 15. CC-Switch + Echo Bird 协作

## 🎯 本课目标

理解两个工具如何互补使用，以及什么时候适合同时用两个。

> ⏱️ **预计时间**：15-20 分钟
> 🔧 **需要**：CC-Switch 和 Echo Bird 都已安装

---

## 🤔 两个工具一起用有什么好处？

虽然 CC-Switch 和 Echo Bird 功能相同，但同时使用有几个好处：

1. **互为备份**：一个工具出问题或不喜欢某个版本，还有另一个可用
2. **分别管不同 Key**：比如 CC-Switch 专门用 OpenAI Key，Echo Bird 专门用 Anthropic Key
3. **对比体验**：同时打开两个工具，问同一个问题，对比回复效果
4. **不绑定单一工具**：两个都熟悉，不怕某个停更

---

## 🔀 方案一：分别管理不同模型

最简单的用法——两个工具各管各的：

```
CC-Switch  → 只用 OpenAI Key（Codex）
Echo Bird  → 只用 Anthropic Key（Claude）
```

### 操作方式

1. 打开 **CC-Switch**，只在模型管理中添加 OpenAI API Key
2. 打开 **Echo Bird**，只在模型管理中添加 Anthropic API Key
3. 需要 Codex 时切到 CC-Switch，需要 Claude 时切到 Echo Bird

> 💡 这样做的好处：Key 分散在两个工具中，不会搞混。而且一个工具出了问题不影响另一个。

---

## 🔀 方案二：双工具同 Key（对比测试）

两个工具都添加相同的 Key，方便对比。

```
CC-Switch  → OpenAI Key + Anthropic Key
Echo Bird  → OpenAI Key + Anthropic Key
```

### 什么时候这样用？

- 你想对比两个工具的界面和体验
- 测试哪个工具在你电脑上更流畅
- 一个工具临时出了问题，无缝切到另一个

---

## 📊 两种方案对比

| 维度 | 方案一（分别管理） | 方案二（双工具同 Key） |
|------|-------------------|----------------------|
| 复杂度 | 🟢 简单，Key不混淆 | 🟡 稍复杂 |
| 备份能力 | 🟡 每个模型只有一个工具管 | 🟢 每个模型都有备份 |
| 适合人群 | 日常使用 | 对比测试、折腾党 |

---

## 💡 实际建议

对于绝大多数人：**选一个主要工具就够了**。两个都装是加分项，不是必选项。

| 你的情况 | 建议 |
|----------|------|
| 刚入门 | 只用 CC-Switch |
| 用了一段时间想尝鲜 | 加装 Echo Bird 试试 |
| 日常使用 | 哪个顺手用哪个，另一个当备份 |
| 重度依赖 | 两个都开着，随时切换 |

---

## 🆘 常见问题

### Q: 两个工具会互相冲突吗？

不会。它们是独立的程序，各自运行，互不影响。

### Q: 同一个 API Key 用在两个工具上会被封吗？

不会。但注意不要重复问同一个问题——那等于浪费钱（两次 API 调用都要付费）。

### Q: 可以同时打开两个工具的窗口吗？

可以。就像你同时开着浏览器和文档编辑器一样，完全没问题。
