# 16. 性能优化与成本控制

## 🎯 本课目标

学会在使用 CC-Switch 和 Echo Bird 时省钱、提速、不浪费。

> ⏱️ **预计时间**：20-30 分钟
> 💰 **重点**：控制 API 花费

---

## 💰 第一：控制成本

### 1. 设置用量上限（最重要！）

在平台上设置花钱的上限，防止意外超支：

**OpenAI**：
1. 访问 https://platform.openai.com/settings/organization/limits
2. 设置每月硬上限（Hard limit）——建议学习阶段设 $10-20
3. 设置软上限（Soft limit）——到了会发邮件提醒你

**Anthropic**：
1. 访问 https://console.anthropic.com/settings/usage
2. 设置 Usage limit

> 🔴 这一步必须做！不要等收到大额账单才后悔。

### 2. 简单问题用便宜模型

在 CC-Switch 中添加模型时，你可以选择不同的版本：

| OpenAI 模型 | 价格（近似） | 适合 |
|------------|------------|------|
| GPT-4o-mini | 💰 便宜 | 简单问答、日常使用 |
| GPT-4o | 💰💰 中等 | 代码生成、中等难度 |

| Anthropic 模型 | 价格（近似） | 适合 |
|---------------|------------|------|
| Claude Haiku | 💰 便宜 | 快速问答、简单任务 |
| Claude Sonnet | 💰💰 中等 | 日常编程、分析 |
| Claude Opus | 💰💰💰 贵 | 复杂推理、高难度任务 |

> 💡 在 CC-Switch 中添加模型时，选择便宜版本作为日常使用。遇到难题再切到贵的。

### 3. 一个问题不要反复问

同一个问题发给两个模型对比是 OK 的。但不要：
- 同一个模型反复问同一个问题（每次都要钱）
- 问题没想清楚就发——想清楚再输入
- 把 AI 当搜索引擎——先搜一下，搜不到的再问 AI

---

## ⚡ 第二：提高效率

### 1. 用两个模型并行

CC-Switch 和 Echo Bird 是独立程序。你可以：

- 在 CC-Switch 里用 Codex 写代码
- 同时在 Echo Bird 里用 Claude 做代码审查

不用等一个回答完了再问另一个。

### 2. 保留对话记录

CC-Switch 通常会保存历史对话。利用这个功能：

- 同一个话题不要开新对话——在旧对话基础上继续问
- 之前问过的问题，翻历史记录找答案，不要重新问

### 3. 算好再问

问之前想清楚：
- 这个问题需要 AI 吗？（"今天星期几"不需要 AI）
- 问题描述够清楚吗？（模糊的问题 AI 也答不好，还得再问一遍）
- 要不要先自己查一下？（搜索引擎免费，AI 按次收费）

---

## 🛡️ 第三：保护 Key 安全

### 在 CC-Switch 中管理 Key

- Key 保存在 CC-Switch 本地，不会上传
- 如果 CC-Switch 出了问题需要重装，记得先记下你的 Key
- 不要在公共电脑上的 CC-Switch 中保存 Key

### 定期检查用量

每周花一分钟：
1. 打开 OpenAI Usage 页面看一眼
2. 打开 Anthropic Usage 页面看一眼
3. 确认花费在预期范围内

发现异常消费，立刻去平台撤销 Key，换一个新的。

---

## 📊 省钱习惯总结

| 习惯 | 省钱效果 |
|------|---------|
| 设置每月硬上限 | 🔴 防破产 |
| 日常用便宜模型 | 🟡 省 50-70% |
| 不要重复问同一个问题 | 🟡 省 10-20% |
| 先搜索再问 AI | 🟡 省 5-10% |
| 定期检查用量 | 🟢 及时发现异常 |
