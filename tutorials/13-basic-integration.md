# 13. Codex + Claude 基础集成

## 🎯 本课目标

理解 Codex 和 Claude 各自的特点，学会在 CC-Switch 中合理切换使用两个模型。

> ⏱️ **预计时间**：20-30 分钟
> 🖥️ **需要**：CC-Switch 已安装并配置好两个模型

---

## 🤔 为什么需要两个 AI 模型？

你已经把 OpenAI Key 和 Anthropic Key 都填入了 CC-Switch。但你可能会问：为什么不能只用其中一个？

想象你有两本字典：
- 一本是 **《编程词典》**：代码、函数、算法查得特别准
- 一本是 **《百科词典》**：解释、分析、写作讲得特别清楚

你会只带其中一本吗？不会——你会两本都带着，看情况用。Codex 和 Claude 就是这样的关系。

---

## 📊 Codex 和 Claude 的差异

| 对比维度 | Codex（OpenAI） | Claude（Anthropic） |
|----------|----------------|---------------------|
| 代码生成 | ⭐⭐⭐ 强项 | ⭐⭐ 也不错 |
| 代码解释 | ⭐⭐ 还行 | ⭐⭐⭐ 更通俗 |
| 长文本分析 | ⭐⭐ 有长度限制 | ⭐⭐⭐ 能处理很长 |
| 逻辑推理 | ⭐⭐ 不错 | ⭐⭐⭐ 更强 |
| 写作润色 | ⭐⭐ 偏技术风格 | ⭐⭐⭐ 更自然 |
| 速度 | 快 | 中等 |

---

## 🎮 在 CC-Switch 中实践

### 练习 1：代码生成对比

1. 打开 CC-Switch
2. 切换到 **Codex**
3. 输入：`用Python写一个函数，找出列表中出现次数最多的元素`
4. 复制 Codex 的回答
5. 切换到 **Claude**
6. 输入**完全一样的问题**
7. 对比两个回答的差异

你可能会发现：
- Codex 的代码更简洁，专注于解决问题
- Claude 的代码可能带更多注释和解释

### 练习 2：解释对比

1. 找一段你之前写的（或网上找的）不太懂的代码
2. 切换到 **Codex**，粘贴代码，输入：`解释这段代码`
3. 记下回答
4. 切换到 **Claude**，粘贴同样的代码和问题
5. 对比两个解释

你可能会发现：
- Codex 的解释偏技术，直接说"这行做了什么"
- Claude 的解释更新手友好，会讲"为什么这样做"

---

## 💡 什么场景用哪个？

```
你要写代码 → 用 Codex
你要看懂代码 → 用 Claude
你要改 bug → 用 Codex
你要理解为什么会有这个 bug → 用 Claude
你要快速回答 → 随便
你要深度分析 → 用 Claude
```

> 💡 规则不绝对。如果你只有一个 Key，用哪个都行。两个 Key 都有，就按上面的建议分工。

---

## 🔄 双模型工作流

最推荐的使用习惯：

```
1. 任务来了 → 先判断是"写"还是"懂"

2. 如果是"写"（写代码、写函数、翻译代码）
   → 用 Codex 生成内容
   → 用 Claude 检查一遍质量

3. 如果是"懂"（解释代码、分析逻辑、找问题）
   → 用 Claude 分析
   → 如果需要改代码，切到 Codex
```

这个"Codex 生成 + Claude 审查"的组合是最实用的。
