# 08. CC-Switch 工具介绍

## 🎯 本课目标

了解 CC-Switch 是什么、它能做什么、以及它为什么对你有用。

> ⏱️ **预计时间**：10-15 分钟
> 📖 **类型**：概念讲解，无需动手

---

## 🤔 CC-Switch 是什么？

**CC-Switch** = Codex-Claude Switch

它是一个**桌面应用程序**——就像你电脑上的 QQ、微信、浏览器一样，双击图标就能打开。不需要写代码，不需要命令行。

它的核心功能：**你提供 API Key，它帮你连接 AI 模型**。

---

## 🎯 它解决了什么问题？

### 普通人的困境

你想用 ChatGPT，可以去网页版。但你想**在自己的电脑上**用 Codex 或 Claude 的完整能力——

- 你得会写代码才能调 API
- 你得懂什么是 endpoint、什么是请求头
- 各种工具配置起来很麻烦

### CC-Switch 的做法

```
你 → 打开 CC-Switch → 粘贴 API Key → 开始使用 AI
```

不需要编程，不需要装一堆东西。就像打开微信就能聊天一样简单。

---

## 🖥️ 它是一个怎样的程序？

CC-Switch 是一个**有图形界面的桌面程序**：

- 双击 `.exe`（Windows）或 `.dmg`（macOS）就能打开
- 有完整的窗口界面，所有操作都通过点击完成
- 有一个**模型管理**功能，你可以在里面添加不同的 AI 模型
- 添加模型时，只需要粘贴对应的 API Key

---

## 🔑 工作原理（极简版）

```
你打开 CC-Switch
    ↓
在「模型管理」中添加一个模型
    ↓
粘贴你的 OpenAI API Key（或 Anthropic API Key）
    ↓
CC-Switch 用这个 Key 连接 AI 服务
    ↓
你可以直接在 CC-Switch 中使用 Codex / Claude
```

CC-Switch 帮你完成了所有技术细节——网络请求、格式转换、错误处理——你只需要关心"我跟 AI 聊什么"。

---

## 📊 CC-Switch 的核心功能

| 功能 | 说明 |
|------|------|
| **模型添加** | 在界面中输入 API Key，添加你想用的模型 |
| **多模型支持** | 同时添加 Codex 和 Claude，随时切换 |
| **图形界面** | 不需要命令行，所有操作点鼠标完成 |
| **即装即用** | 下载 → 安装 → 打开 → 用 |
